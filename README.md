# InstaClip

InstaClip is an AI-assisted workflow for turning long-form creator content into reviewable short-form clip candidates.

## Public edition status

This repository is the focused public edition and is currently under active extraction and production hardening. The complete working MVP remains private while its security, licensing, data, dependency, and product boundaries are audited.

The goal is a reliable path from supported source media to a polished vertical clip—not a general-purpose video editor or an unbounded collection of experimental tools.

## Contribution model

Work is issue-driven and independently verified. Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing changes, use the repository templates, and include reproducible evidence in every pull request.

Do not publish private source, credentials, user content, licensed media, paid assets, or model prompts from the private MVP.

## Security

Please follow [SECURITY.md](SECURITY.md) and report vulnerabilities privately rather than opening a public exploit report.
